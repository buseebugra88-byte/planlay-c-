# Ayşenaz PWA Paketi

Bu paket uygulamayı telefonda “ana ekrana eklenebilir” mini uygulama gibi kullanmak içindir.

GitHub’a aynı klasöre yükle:

- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png
- apple-touch-icon.png

Sonra GitHub Pages adresini açıp telefonda ana ekrana ekle.

Güncelleme sonrası eski sürüm görünürse tarayıcıda sert yenileme yap veya telefon kısayolunu silip yeniden ekle.
