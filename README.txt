Ayşenaz PWA - tam yedekli sürüm

Kullanım:
1) GitHub Pages deposuna bu klasördeki dosyaları yükleyin.
2) iPhone Safari ile sayfayı açın.
3) Paylaş > Ana Ekrana Ekle deyin.

Veri güvenliği:
- Veriler cihazdaki localStorage içinde saklanır.
- Her ekleme/silme/tamamlama sonrası otomatik kayıt yapılır.
- Yedekleme Merkezi'nden JSON yedek indirilebilir.
- Güncelleme yaparken localStorage key adını değiştirmeyin: aysenaz_full_state


Not: Bu sürümde ikonlar önceki kaplumbağa ikonlarına geri alınmıştır.
